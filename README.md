# Plumbline

> Status: day 0, planning only. No working code yet.

A deterministic mock LLM inference server with known per-token timestamps, used as an answer key to measure how accurately LLM benchmarking tools report TTFT, inter-token latency, throughput and tail latency.

See `docs/PLAN.md` for the plan and `docs/PROGRESS.md` for what is actually done.
